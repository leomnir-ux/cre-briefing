# CRE Weekly Briefing Project

This project produces a weekly commercial real estate briefing that will later feed a website.

## How to work here
- Follow spec.md for every briefing. Do not change the section headings, because the website splits files on them.
- Save each weekly briefing in briefings/ as YYYY-MM-DD.md, using the end date of the week.
- Keep a short note in ai-log/ for each change to spec.md: what went wrong, and the rule that fixes it.
- Never write a figure that is not in a cited source. Leave undisclosed figures undisclosed.
- Links must be clean URLs with no utm_source or other tracking parameters.
- The user is a beginner with no coding background. Explain what you change in plain language.
- Writing style: direct, no filler, no em dashes.
